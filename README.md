# WizardZ - Animated Landing Page 🪄

A modern, responsive landing page built with HTML, CSS, and [GSAP (GreenSock Animation Platform)](https://greensock.com/gsap/) to sharpen my frontend development and web animation skills.

## 🚀 About the Project

**WizardZ** is a practice project designed to push my boundaries with UI/UX layout design and fluid micro-interactions. The goal was to take a clean agency-style landing page design and bring it to life using advanced CSS styling and smooth JavaScript animations.

### ✨ Features
* **Modern Hero Section:** Clean navigation, compelling headline copy, and an eye-catching hero illustration.
* **Iconography:** Integrated [Remix Icons](https://remixicon.com/) for a sleek, consistent icon set.
* **Responsive Layout:** Structured to adapt cleanly across different screen sizes.
* **Animation-Ready:** Built with modular HTML sections (`section1`, navigation bars, and grid components) specifically optimized for GSAP timelines and scroll-triggered animations.

## 🛠️ Built With

* **HTML5** - Semantic markup structure.
* **CSS3** - Custom styling, flexbox/grid layouts.
* **JavaScript (ES6+)** - Interactive logic and animation triggers.
* **GSAP** - For smooth, high-performance web animations.
* **RemixIcon** - Vector icons.

## 🎯 Purpose & Learning Goals

I built this project to:
* Master GSAP core concepts (such as timelines, easing, and stagger effects).
* Improve precision in translating UI designs into responsive frontend code.
* Better structure CSS architecture for clean, scalable animation integration.
